# 芯片全局布线 MVP

## 功能范围

当前版本实现的是教学和原型验证用途的二维 G-Cell 全局布线，不是可直接用于流片的详细布线器。

求解流程如下：

1. 随机生成二维网格、矩形禁布区和若干两端点网络。
2. Attention 网络读取每个网络的端点、曼哈顿距离和局部障碍密度。
3. 策略以自回归方式输出所有网络的布线顺序。
4. A* 路由器按照该顺序逐条走线，并累计线长、转弯、拥塞溢出和未布通网络。
5. REINFORCE 使用最终布线代价作为回报，训练网络排序策略。

目标函数为：

```text
objective =
    wirelength
    + bend_weight * bend_count
    + overflow_weight * overflow
    + unrouted_penalty * unrouted_count
```

目标值越小越好。训练界面的 Reward 是归一化后的负目标值，因此越大越好。

## 页面参数

| 参数 | 默认值 | 范围 | 含义 |
|---|---:|---:|---|
| 网格宽度 | 18 | 8-40 | G-Cell 横向数量 |
| 网格高度 | 18 | 8-40 | G-Cell 纵向数量 |
| 两端点网络数量 | 12 | 4-40 | 需要连接的网络数量 |
| 障碍率 | 0.10 | 0-0.30 | 随机宏单元禁布区占比 |
| 边容量 | 1 | 1-4 | 每条网格边允许承载的路径数量 |

首版固定使用 `Attention + REINFORCE + 随机数据`，暂不支持上传芯片数据集。

## 可视化

每个评估样本生成：

- 训练前布线图：初始策略给出的网络顺序及 A* 走线。
- 训练后布线图：训练后策略给出的网络顺序及 A* 走线。
- 拥塞热力图：颜色表示经过单元格的路径数量。
- 动态布线 GIF：按照训练后顺序逐条显示网络走线过程。

结果区域同时显示训练前后目标值、目标值改善、平均线长、溢出量和布通率。

## 当前限制

- 仅支持二维、单层、正交网格和两端点网络。
- A* 路由在 CPU 上执行，网络数量和网格范围受到页面上限约束。
- 当前实例为随机生成，尚未接入 DEF/LEF、Bookshelf 或自定义 JSON 数据。
- 未实现多层过孔代价、时序约束、串扰、设计规则检查及 rip-up and reroute。
- 策略只优化网络顺序，具体路径仍由确定性 A* 路由器生成。
