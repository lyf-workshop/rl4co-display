## 真实流程与错误状态

- 实际跑通注册 → 登录 → 首页；读取真实 GPU 设备与可用显存。
- TSP 小规模 GPU 训练跑通启动 → SSE → 图表与日志 → 完成 → 结果文件与 Checkpoint → 算法对比。
- 另一真实训练跑通暂停 → 页面刷新恢复 → 浏览器离线 / 恢复连接 → 恢复训练 → 中止确认 → GPU 释放。刷新及重连没有发送额外 `start_training` 请求。
- 完成后的 Session URL 连续刷新恢复结果、7 个图像产物及真实训练配置。服务端终态队列快照行为有独立单元测试。
- 数据集上传 / 下载 / 使用 / 删除，以及 Checkpoint 和 Session 产物删除使用真实接口。删除失败时确认窗口保留，恢复网络后可重试成功。
- 验证不合法参数、兼容性读取失败、文件读取失败及重试、上传格式错误、助手中断与停止生成。
- 确认窗口验证 Esc、焦点循环、焦点返回、请求中禁止重复操作，以及位于助手 Drawer 上层。
- 真实 Ollama 模型返回 Loss 解释；快捷问题提交实际 prompt。配置建议应用后字段更新，训练启动次数不增加。
- 最后通过文件页的确认窗口清理验收账户训练产物，剩余文件与数据集均为 0；实际退出登录后访问受保护页面正确跳转登录。该流程没有 console error 或 page error。独立验收账户及其数据库训练历史保留，不删除数据库记录。
